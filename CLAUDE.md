## Design Context

This is a **brand-register** personal portfolio for a full-stack/product engineer who is also a practicing fine artist (oil painting, mixed media). Goal is reputation/network, not conversion — see [PRODUCT.md](PRODUCT.md) for the full strategic brief and [DESIGN.md](DESIGN.md) for the visual system ("The Studio Flythrough").

Key rules to respect in any UI work:
- **Bold & experimental, studio-not-showroom** — push intensity, don't sand it down toward generic-safe.
- **Flat by default** — no `box-shadow` anywhere; depth comes from hairline borders and tonal shifts only.
- **One accent color, used rarely** (Studio Red `#ff3b14` dark / Studio Blue `#155dfc` light) — never as a fill or button background.
- **Four locked type roles** — Druk Wide (display, 700/900 only), Austin (serif/editorial), Graphik (body), IBM Plex Mono (nav/labels/technical).
- Avoid generic dev-portfolio patterns: card grids, gradient text, tracked uppercase eyebrows, numbered section markers as decoration.
- Both the engineering work and the fine-art work must get equal visual weight — never demote the art to a secondary section.
